jQuery $

Una librería de JavaScript creada para simplificar tareas comunes de desarrollo web.

01

¿Qué es?

jQuery es una librería de JavaScript que nació para facilitar la selección y modificación de elementos HTML, los eventos, efectos y otras tareas frecuentes.

02

La sintaxis $

El símbolo $ es una forma corta y característica de acceder a elementos y métodos de jQuery.

03

Ventajas y desventajas

Ventaja: sintaxis sencilla y útil para proyectos antiguos. Desventaja: JavaScript moderno ya incluye muchas funciones que antes requerían jQuery.

JavaScript vs. jQuery

JavaScript Vanilla

document
  .querySelector("#caja")
  .classList.toggle("activo");

jQuery

$("#caja")
  .toggleClass("activo");
