TECNOLOGÍA 01

JavaScript Vanilla

El lenguaje que permite agregar comportamiento e interactividad a una página web.

01

¿Qué es?

JavaScript es un lenguaje de programación utilizado principalmente para crear páginas web interactivas. Puede responder a acciones del usuario, modificar contenido y trabajar con datos.

02

HTML + CSS + JS

HTML construye la estructura, CSS define el aspecto visual y JavaScript agrega comportamiento.

03

Conceptos básicos

Variables: guardan datos. Funciones: agrupan instrucciones. Eventos: ejecutan acciones cuando ocurre algo como un click.

EJEMPLO PRÁCTICO

Un botón que cambia un mensaje

El evento click llama a una función y cambia el texto mostrado en pantalla.

const boton = document.querySelector("#boton");
const mensaje = document.querySelector("#mensaje");

boton.addEventListener("click", () => {
  mensaje.textContent = "¡JavaScript está funcionando!";
});

Prueba el ejemplo

Presiona el botón para cambiar este mensaje.
