JSON { }

Formato ligero y fácil de leer para almacenar e intercambiar información.

01

¿Qué es JSON?

JSON significa JavaScript Object Notation. Utiliza una estructura de objetos y arreglos para representar datos de manera organizada.

02

Clave y valor

Los datos se organizan como pares clave: valor. También puede contener objetos dentro de otros objetos y arreglos.

03

Uso en aplicaciones

Una aplicación puede enviar una solicitud a un servidor o API y recibir una respuesta en JSON para mostrar información al usuario.

Objeto JS vs. cadena JSON

Objeto JavaScript

const producto = {
  nombre: "SmartBand X1",
  precio: 49.99,
  disponible: true
};

JSON

{
  "nombre": "SmartBand X1",
  "precio": 49.99,
  "disponible": true
}
