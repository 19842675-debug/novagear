# NovaGear — Proyecto Web de Tecnologías

Proyecto educativo realizado en HTML, CSS y JavaScript.

## Contenido
- Identidad de marca y producto SmartBand X1.
- Investigación de JavaScript Vanilla.
- Investigación de jQuery.
- Investigación de JSON.
- Investigación de Web Hosting y Dominios.
- Cuestionario interactivo de 10 preguntas.
- Ejemplos de código y comparación JS vs jQuery.

## Ejecutar en Visual Studio Code
1. Extrae la carpeta.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` en el navegador o utiliza Live Server.
4. Para jQuery se utiliza la CDN oficial de jQuery, por lo que esa página necesita conexión a internet para cargar la librería.

## GitHub
Crea un repositorio público y sube todos los archivos.

Ejemplo:
git init
git add .
git commit -m "Proyecto inicial NovaGear"
git branch -M main
git remote add origin TU_URL_DE_GITHUB
git push -u origin main

## Vercel
1. Inicia sesión en Vercel.
2. Importa el repositorio de GitHub.
3. Selecciona el proyecto.
4. Para este sitio no necesitas un comando de build.
5. Haz clic en Deploy.
6. Vercel generará una URL pública.

## Entrega
- URL del repositorio público de GitHub.
- URL del proyecto desplegado en Vercel.
