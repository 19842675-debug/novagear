Hosting & Dominios

Los elementos que permiten publicar un sitio y encontrarlo en internet.

01

Web Hosting

Es el servicio que almacena los archivos de un sitio para que puedan ser consultados a través de internet.

02

Tipos

Compartido: varios sitios comparten recursos. VPS: recursos virtualizados con mayor control. Nube: utiliza infraestructura distribuida y escalable.

03

Vercel

Vercel permite desplegar proyectos web conectándolos con repositorios como GitHub. Es especialmente práctico para sitios estáticos y aplicaciones frontend.

DOMINIO

¿Cómo funciona una dirección web?

Un dominio es el nombre que identifica un sitio en internet. Un TLD es su extensión, como .com, .net u .org. Un subdominio es una sección que aparece antes del dominio, por ejemplo blog.ejemplo.com.
